# KSA — редизайн сайта

Новый дизайн главной страницы [ksa-fdi.kz](https://ksa-fdi.kz/) (Казахстанская стоматологическая ассоциация).
Стиль и моушен — по мотивам rapideyachtgroup.com, блок «Направления» — по мотивам секции Frontiers на anveril.com.

## Стек
Статический сайт без сборки: `index.html`, `style.css`, `main.js`, `assets/`.
Анимации — GSAP + ScrollTrigger, плавный скролл — Lenis (подключены с CDN).

## Локальный запуск
```bash
python3 -m http.server 5178
```
Открыть http://localhost:5178

## Страницы
- `index.html` — лендинг «Членство в КСА» по ТЗ: hero → что даёт членство → стоимость и выгода → как вступить (3 шага, листаются скроллом) → об ассоциации и партнёры (AIDENTIS, FDI, остальные) → FAQ → финальный CTA.
- `events.html` — «Наши мероприятия»: список ближайших мероприятий как маркетплейс (календарь, фильтры, поиск, карточка мероприятия с записью).

## Как добавить мероприятие
Открыть `events.js`, добавить объект в массив `EVENTS` (афишу положить в `assets/events/`). Прошедшие мероприятия скрываются автоматически.

## Заявки
Каждая кнопка «Вступить в КСА» / «Записаться» открывает попап с формой.
Сейчас заявка уходит в WhatsApp КСА (+7 701 773-24-56) готовым сообщением.
Чтобы принимать заявки на сервер/CRM, задайте `window.KSA_FORM_ENDPOINT = 'https://…'` перед подключением `main.js` — форма отправит JSON POST-запросом.
